## 3. SEO Implementation & Hreflang Alignment

1. **Hreflang Tags:** Implemented across all 848 prerendered pages via `getLocalizedAlternates(locale, path)` with reciprocal tags and `x-default` mapped to `/en`.
2. **Canonical Links:** Each language variant links to its absolute preferred URL: `https://duyufalrahmanvip.com/{locale}/{path}`.
3. **Structured Data:** Schema.org `LocalBusiness`, `TaxiService`, `TouristInformationCenter`, and `FAQPage` embedded with SAR currency units.

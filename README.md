## 🌟 أبرز مميزات المنصة

1. **تصميم ملكي فاخر وسرعة فائقة (UI/UX):**
   - تصميم متجاوب فائق السرعة مبني بـ Semantic HTML5 و Tailwind CSS و Vanilla JavaScript.
   - هوية بصرية سعودية راقية تمزج بين الأخضر الزمردي الداكن الملكي، الأسود الفاخر، واللمسات الذهبية، مع خطوط عربية أصيلة (`Tajawal` و `Cairo`).
   - دعم كامل للغتين: **العربية (RTL)** والإنجليزية **(LTR)** مع تبديل لحظي سلس بدون إعادة تحميل الصفحة.
   - محول عملات لحظي يدعم 5 عملات عالمية رئيسية: **SAR (الريال السعودي)**، **USD (الدولار الأمريكي)**، **GBP (الجنيه الإسترليني)**، **EUR (اليورو)**، و **EGP (الجنيه المصري)**، مع تحديث فوري لجميع الأسعار في كافة الأقسام وحاسبة الحجز.

2. **محرك الحجز الذكي التفاعلي المكون من 3 خطوات (3-Step Booking Engine):**
   - **الخطوة 1 (المسار والتوقيت):** قائمة مسارات شاملة (مطار جدة إلى مكة، مكة إلى المدينة، مطار المدينة إلى الفندق، جولات المزارات بمكة والمدينة، مطار الملك خالد بالرياض، وحجز سيارة بسائق باليوم/الساعة بالرياض) مع تاريخ ووقت الرحلة ورقم رحلة الطيران لتتبع التأخير مجاناً.
   - **الخطوة 2 (السيارة والسعر التلقائي):** حساب فوري للسعر الثابت المحدث بالعملة المختارة لخمس فئات:
     1. سيدان اقتصادية (كامري / سوناتا - 3 ركاب + 2 حقائب)
     2. عائلية مريحة (ستاريا / H1 - 7 ركاب + 5 حقائب)
     3. فخامة VIP (جمس يوكن XL - 7 ركاب + 6 حقائب)
     4. ميني باص عائلي (تويوتا هايس - 10 ركاب + 10 حقائب)
     5. باص مجموعات (تويوتا كوستر - 20 راكب + 15 حقيبة)
   - **الخطوة 3 (بيانات المسافر والدفع والربط المباشر مع الواتساب):** إدخال اسم العميل ورقم هاتفه، واختيار طلبات خاصة (كرسي أطفال، كرسي متحرك، ضيافة ماء زمزم بارد)، واختيار طريقة الدفع (نقداً عند الوصول أو إلكتروني مدى/Apple Pay).
   - **زر تأكيد الحجز الفوري:** يولد رسالة واتساب منسقة ومفصلة بكل بيانات الرحلة ورقم حجز مرجعي فريد ويفتح محادثة مباشرة مع رقم الشركة: `+966567588261`.

3. **أقسام الصفحة التسويقية والتنافسية:**
   - **أسطول السيارات (Fleet Showcase):** بطاقات تفاعلية مميزة مع زر حجز سريع ينقل السيارة تلقائياً إلى محرك الحجز.
   - **جدول أسعار المسارات الثابتة (Pricing Matrix Table):** جدول مهيكل ومصمم خصيصاً ليظهر كإجابة مميزة (Featured Snippet) على جوجل.
   - **المزايا التنافسية الست (Competitive Pillars):** الاستقبال باللوحة في المطار، تتبع الطيران وانتظار 90 دقيقة مجاناً، دفع 100% عند الوصول بدون دفعة أولى، ماء زمزم وواي فاي وشواحن، وتغطية العاصمة الرياض، وإشراف عمليات 24/7.
   - **تقييمات معتمرين وضيوف دوليين:** من بريطانيا، مصر، ماليزيا، وغيرها.
   - **الأسئلة الشائعة (Answer-First FAQ):** 8 أسئلة وإجابات شاملة بصيغة ذكية متوافقة تماماً مع خوارزميات محركات البحث والذكاء الاصطناعي (ChatGPT, Gemini, Perplexity).

4. **السيو الدولي وتحسين محركات البحث التوليدية (AEO / GEO / SEO):**
   - وسوم Open Graph و Twitter Cards وميتاتاج الوصف والكلمات المفتاحية.
   - وسوم `hreflang` الدولية الموجهة لـ 9 دول ولغات رئيسية (`ar`, `ar-SA`, `ar-EG`, `en`, `en-GB`, `en-US`, `ur`, `id`, `fr`).
   - كود `Schema.org JSON-LD` متقدم يربط `TaxiService` و `LocalBusiness` و `OfferCatalog` و `AggregateRating` و `FAQPage`.
   - ملف `llms.txt` رسمي جاهز في جذر الموقع لتعريف عناكب الذكاء الاصطناعي ببيانات المنصة وأرقامها ومساراتها لترشيحها كخيار أول.
   - ملفات `robots.txt` و `sitemap.xml` مهيأة ومعتمدة لمحركات البحث.

## 🚀 كيفية التشغيل والنشر

### 1. التشغيل المحلي الفوري:
يمكنك ببساطة النقر المزدوج على ملف `index.html` في جهازك ليفتح في المتصفح بكامل ميزاته وتفاعليته وسرعته، وتجربة تبديل اللغات والعملات وحاسبة الحجز وتأكيد الواتساب.

### 2. النشر على الإنترنت (مجاناً وبسرعة):
- **Vercel / Netlify / Cloudflare Pages:** اسحب المجلد وأفلته مباشرة، أو اربطه مع مستودع GitHub وسيعمل فوراً دون الحاجة لأي بناء (Zero Build Configuration).
- **استضافات cPanel / VPS:** ارفع الملفات مباشرة داخل مجلد `public_html`.
